PANDUAN — Studio Musik NadaKita
Website siap pakai (Source Code Gratis by LocaGo Creative).

CARA PAKAI
1. Buka file index.html dengan double-click — website langsung tampil di browser.
2. Untuk online: upload file index.html ke hosting statis apa pun
   (Netlify, Vercel, GitHub Pages, atau hosting lain). Tidak perlu database/server.

CARA MENYESUAIKAN
- Nama usaha: cari "Studio Musik NadaKita" di index.html, ganti dengan nama usahamu.
- Nomor WhatsApp: cari "6281234567890" di index.html, ganti dengan nomor WA
  (format internasional, contoh: 6281234567890). Nomor yang tampil di footer
  "0812-3456-7890" juga diganti.
- Harga & katalog: ubah daftar harga di bawah ini di file index.html
  (bagian SITE / daftar item) — harga dihitung otomatis oleh JavaScript.
- Warna: ubah kode warna di bagian atas index.html (primary/dark/accent).
- Gambar hero: ganti URL Unsplash di bagian <section> hero.

DAFTAR HARGA CONTOH (harga contoh — sesuaikan dengan harga usahamu):
  - Studio A — Band: Rp150.000 — Full band set: drum, 2 gitar, bass & PA
  - Studio B — Akustik: Rp100.000 — Ruangan akustik hangat untuk latihan unplugged
  - Studio C — Rekaman: Rp200.000 — Ruangan rekaman + mixing console
  - Studio D — Drum: Rp120.000 — Ruangan latihan drum, kedap suara

FITUR
  - 4 ruangan studio dengan tarif per jam
  - Kalkulator tarif: ruangan × durasi + alat tambahan
  - Form booking: tanggal, jam mulai & durasi
  - Kode booking otomatis (STD-XXXXXX) + konfirmasi via WhatsApp
  - Peralatan lengkap & ruangan kedap suara
  - Panduan PANDUAN.txt: cara ganti nama, WA, tarif & ruangan

CATATAN
- Semua harga & nama usaha di situs ini adalah CONTOH FIKTIF untuk demo.
- Jangan klaim testimoni/nama orang nyata sebelum diganti dengan data asli.
- File ini + index.html adalah isi ZIP unduhan.
