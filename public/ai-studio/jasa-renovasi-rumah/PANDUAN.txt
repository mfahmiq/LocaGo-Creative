PANDUAN — RENORUMAH (Kalkulator Biaya Online)
=============================================
Website kalkulator biaya online "RenoRumah".
Source code gratis by LocaGo Creative (locagocreative.my.id).

CARA MEMBUKA
------------
1. Double-click file index.html — website langsung terbuka di browser.
   (Tidak perlu install apa pun.)
2. Atau upload file index.html ke hosting statis apa pun
   (Netlify, Vercel, GitHub Pages, Niagahoster, dll).

FITUR
-----
- Kalkulator estimasi: jenis renovasi × luas × material
- Slider luas 5–200 m² + 2 pilihan material (standard/premium)
- 4 jenis renovasi dengan harga per m² transparan
- Profil jasa renovasi, garansi & testimoni pelanggan
- Konsultasi & survey gratis via WhatsApp

CARA MENYESUAIKAN (edit file index.html dengan Notepad / VS Code)
-----------------------------------------------------------------
- Nama jasa & nomor WhatsApp : cari WA_NUMBER = "6281234567919" di bagian bawah file, ganti dengan nomor WA kamu (format: 62 + nomor).
- Harga renovasi & material : cari bagian const FIELDS = [ ... ] lalu ubah price (per m²) dan mult (pengali material).
- Alamat & jam buka : cari bagian "Lokasi & Jam Buka" di HTML.
- Warna tema : cari tailwind.config di <head> (warna cokelat/amber).

CATATAN
-------
- Gambar memakai URL Unsplash — butuh internet saat pertama dibuka.
- Semua data keranjang/booking hanya tersimpan di browser pengunjung.
- Bebas dipakai & dimodifikasi untuk usahamu. Dilarang dijual kembali
  sebagai produk berbayar tanpa izin LocaGo Creative.
