PANDUAN — BUGARFIT GYM & FITNESS (Website Gym & Fitness Center)
===================================================================
Website gym "BugarFit Gym & Fitness".
Source code gratis by LocaGo Creative (locagocreative.my.id).

CARA MEMBUKA
------------
1. Double-click file index.html — website langsung terbuka di browser.
   (Tidak perlu install apa pun.)
2. Atau upload file index.html ke hosting statis apa pun
   (Netlify, Vercel, GitHub Pages, Niagahoster, dll).

FITUR
-----
- Paket membership (6 paket: harian, bulanan, 3/6/12 bulan, pelajar)
  — klik untuk memilih, harga & fasilitas tampil otomatis
- Kalkulator BMI: masukkan berat & tinggi badan = nilai BMI,
  kategori (kurus/normal/gemuk/obesitas) + rekomendasi paket & kelas
- Jadwal kelas mingguan (HIIT, Strength, Yoga, Zumba) dengan pelatih
- Form booking trial gratis 1x: pilih kelas & tanggal — konfirmasi
  otomatis ke WhatsApp
- Testimoni member, perlengkapan yang perlu dibawa, lokasi & jam buka

CARA MENYESUAIKAN (edit file index.html dengan Notepad / VS Code)
-----------------------------------------------------------------
- Nama gym & nomor WhatsApp : cari WA_NUMBER = "6281234567890"
  di bagian bawah file, ganti dengan nomor WA kamu (format: 62 + nomor).
- Harga & nama paket : cari bagian const PACKAGES = [ ... ] lalu ubah
  name, price, dan desc.
- Jadwal kelas : cari bagian "Jadwal Kelas Mingguan" di HTML, ubah
  nama kelas, hari, jam, dan pelatih.
- Alamat & jam buka : cari bagian "Lokasi & Jam Buka" di HTML.
- Warna tema : cari tailwind.config di <head> (warna gym/lime).
