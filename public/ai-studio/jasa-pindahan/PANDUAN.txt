PANDUAN — PINDAHYUK (Kalkulator Biaya Online)
=============================================
Website kalkulator biaya online "PindahYuk".
Source code gratis by LocaGo Creative (locagocreative.my.id).

CARA MEMBUKA
------------
1. Double-click file index.html — website langsung terbuka di browser.
   (Tidak perlu install apa pun.)
2. Atau upload file index.html ke hosting statis apa pun
   (Netlify, Vercel, GitHub Pages, Niagahoster, dll).

FITUR
-----
- Kalkulator estimasi: layanan + jarak + kendaraan
- Slider jarak 5–100 km + 3 pilihan kendaraan
- Tarif per km transparan (Rp15.000/km)
- Profil jasa pindahan, asuransi & testimoni pelanggan
- Booking survey gratis via WhatsApp

CARA MENYESUAIKAN (edit file index.html dengan Notepad / VS Code)
-----------------------------------------------------------------
- Nama jasa & nomor WhatsApp : cari WA_NUMBER = "6281234567908" di bagian bawah file, ganti dengan nomor WA kamu (format: 62 + nomor).
- Harga layanan & tarif km : cari bagian const FIELDS = [ ... ] lalu ubah price (harga dasar) dan tarif per km di CALC_JS.
- Alamat & jam buka : cari bagian "Lokasi & Jam Buka" di HTML.
- Warna tema : cari tailwind.config di <head> (warna indigo).

CATATAN
-------
- Gambar memakai URL Unsplash — butuh internet saat pertama dibuka.
- Semua data keranjang/booking hanya tersimpan di browser pengunjung.
- Bebas dipakai & dimodifikasi untuk usahamu. Dilarang dijual kembali
  sebagai produk berbayar tanpa izin LocaGo Creative.
