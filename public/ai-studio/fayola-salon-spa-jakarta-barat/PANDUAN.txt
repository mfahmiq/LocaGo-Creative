PANDUAN — Fayola Salon Spa (Salon & Kecantikan)
================================================================
Prototype website kasar untuk "Fayola Salon Spa" (Jakarta Barat) — dibuat dengan
Google AI Studio oleh LocaGo Creative (locagocreative.my.id).
Ini PROTOTYPE: isi di bawah masih contoh dan WAJIB disesuaikan dengan
data asli usahamu sebelum dipakai resmi.

CARA MEMBUKA
------------
1. Double-click file index.html — website langsung terbuka di browser.
   (Tidak perlu install apa pun.)
2. Atau upload file index.html ke hosting statis apa pun
   (Netlify, Vercel, GitHub Pages, Niagahoster, dll).

FITUR
-----
- Daftar layanan (contoh) — klik untuk memilih, bisa lebih dari satu
- Daftar stylist (contoh) dengan spesialisasi & rating — bisa dipilih
- Galeri foto tempat & hasil kerja
- Form booking: pilih stylist, layanan, tanggal & jam — keluar KODE
  BOOKING (cth: FS-123456) + konfirmasi otomatis ke WhatsApp
- Testimoni, tips sebelum datang, lokasi & jam buka

CARA MENYESUAIKAN (edit file index.html dengan Notepad / VS Code)
-----------------------------------------------------------------
- Nama usaha & nomor WhatsApp : cari WA_NUMBER = "6283160123226"
  di bagian bawah file, ganti dengan nomor WA kamu (format: 62 + nomor).
- Layanan/menu : cari bagian const SERVICES = [ ... ] (atau const MENU)
  lalu ubah name, desc, dan icon. HARGA: tambahkan sendiri harga asli —
  prototype ini sengaja TIDAK mencantumkan harga (tanya via WA).
- Nama staf : cari bagian const STAFF = [ ... ] lalu ganti "Barber 1" /
  "Stylist 1" dengan nama tim asli, beserta spesialisasi & rating.
- Testimoni : ganti 3 testimoni contoh di bagian "Kata Mereka" dengan
  testimoni asli pelangganmu.
- Foto galeri : ganti URL Unsplash dengan foto asli tempat/usahanmu.
- Alamat & jam buka : cari bagian "Lokasi & Jam Buka" di HTML.
- Warna tema : cari tailwind.config di <head>.
