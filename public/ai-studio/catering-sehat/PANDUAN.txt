PANDUAN — SEHATBOX (Kalkulator Biaya Online)
=============================================
Website kalkulator biaya online "SehatBox".
Source code gratis by LocaGo Creative (locagocreative.my.id).

CARA MEMBUKA
------------
1. Double-click file index.html — website langsung terbuka di browser.
   (Tidak perlu install apa pun.)
2. Atau upload file index.html ke hosting statis apa pun
   (Netlify, Vercel, GitHub Pages, Niagahoster, dll).

FITUR
-----
- Kalkulator langganan: paket × hari/minggu × minggu − diskon
- 4 paket catering sehat dengan harga per hari
- Diskon 5% untuk langganan 4 minggu
- Profil catering, ahli gizi & testimoni pelanggan
- Pesan & konsultasi via WhatsApp

CARA MENYESUAIKAN (edit file index.html dengan Notepad / VS Code)
-----------------------------------------------------------------
- Nama catering & nomor WhatsApp : cari WA_NUMBER = "6281234567898" di bagian bawah file, ganti dengan nomor WA kamu (format: 62 + nomor).
- Harga paket & diskon : cari bagian const FIELDS = [ ... ] lalu ubah price (per hari) dan disc (diskon langganan).
- Alamat & jam antar : cari bagian "Lokasi & Jam Buka" di HTML.
- Warna tema : cari tailwind.config di <head> (warna hijau lime).

CATATAN
-------
- Gambar memakai URL Unsplash — butuh internet saat pertama dibuka.
- Semua data keranjang/booking hanya tersimpan di browser pengunjung.
- Bebas dipakai & dimodifikasi untuk usahamu. Dilarang dijual kembali
  sebagai produk berbayar tanpa izin LocaGo Creative.
