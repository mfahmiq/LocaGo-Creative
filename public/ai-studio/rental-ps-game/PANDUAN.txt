PANDUAN — ARENAPLAY (Jasa Booking Online)
=============================================
Website booking online "ArenaPlay".
Source code gratis by LocaGo Creative (locagocreative.my.id).

CARA MEMBUKA
------------
1. Double-click file index.html — website langsung terbuka di browser.
   (Tidak perlu install apa pun.)
2. Atau upload file index.html ke hosting statis apa pun
   (Netlify, Vercel, GitHub Pages, Niagahoster, dll).

FITUR
-----
- Rental PS5 / PS4 / PS5 + TV 55 inch dengan harga per jam
- Durasi 1–12 jam, harga terhitung otomatis
- Tambahan: stik, snack, game premium
- Form booking tanggal/jam dengan kode booking otomatis (AP-XXXXXX)
- Konfirmasi booking via WhatsApp

CARA MENYESUAIKAN (edit file index.html dengan Notepad / VS Code)
-----------------------------------------------------------------
- Nama rental & nomor WhatsApp : cari WA_NUMBER = "6281234567895" di bagian bawah file, ganti dengan nomor WA kamu (format: 62 + nomor).
- Harga konsol & tambahan : cari bagian const PKGS = [ ... ] dan const ADDONS = [ ... ] lalu ubah name, price, dan features.
- Alamat & jam buka : cari bagian "Lokasi & Jam Buka" di HTML.
- Warna tema : cari tailwind.config di <head> (warna indigo).

CATATAN
