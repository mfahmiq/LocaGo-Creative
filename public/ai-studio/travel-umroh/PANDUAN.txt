PANDUAN — BAROKAHTOUR (Jasa Booking Online)
=============================================
Website booking online "BarokahTour".
Source code gratis by LocaGo Creative (locagocreative.my.id).

CARA MEMBUKA
------------
1. Double-click file index.html — website langsung terbuka di browser.
   (Tidak perlu install apa pun.)
2. Atau upload file index.html ke hosting statis apa pun
   (Netlify, Vercel, GitHub Pages, Niagahoster, dll).

FITUR
-----
- 3 paket umroh dengan harga transparan per jamaah
- Jumlah jamaah 1–10 dengan diskon 5% untuk rombongan 4 jamaah
- Tambahan: upgrade hotel bintang 5, pendamping lansia, ziarah Madinah
- Form booking tanggal keberangkatan dengan kode booking otomatis (BT-XXXXXX)
- Total harga otomatis & konfirmasi via WhatsApp

CARA MENYESUAIKAN (edit file index.html dengan Notepad / VS Code)
-----------------------------------------------------------------
- Nama travel & nomor WhatsApp : cari WA_NUMBER = "6281234567907" di bagian bawah file, ganti dengan nomor WA kamu (format: 62 + nomor).
- Harga paket & tambahan : cari bagian const PKGS = [ ... ] dan const ADDONS = [ ... ] lalu ubah name, price, dan features.
- Alamat & jam buka : cari bagian "Lokasi & Jam Buka" di HTML.
- Warna tema : cari tailwind.config di <head> (warna hijau zamrud).

CATATAN
-------
- Gambar memakai URL Unsplash — butuh internet saat pertama dibuka.

  sebagai produk berbayar tanpa izin LocaGo Creative.
