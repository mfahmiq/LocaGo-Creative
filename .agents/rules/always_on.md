# Project Directive: Context7, Ponytail, & OpenDesign

Always apply the following 3 systems:
1. **Context7**: Use Context7 MCP server (`resolve-library-id`, `query-docs`) for all library, Tailwind, React, and framework documentation lookup.
2. **Ponytail**: Apply the ladder of restraint. Write minimal code, cut bloat, reuse existing code, avoid speculative architecture, and prefer native web standards.
3. **OpenDesign**: Eliminate AI slop (no generic gradient blobs, no emoji badges, no heavy shadows, no fake marketing buzzwords). Build crisp, editorial, minimalist, and authentic user interfaces.
